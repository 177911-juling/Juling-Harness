# Juling Harness 1.0.1

Juling Harness 1.0.1 将新建对话欢迎区顶部图标替换为应用 Logo，并首次通过 Release 工作流同时提供 Windows、macOS 与 Linux 客户端。内置 Runtime 保持为 **OMP 18.20.2 / `18.20.2-harness.18`**。

## 本版内容

- 新建对话欢迎区使用现有应用 Logo，保留 72×72 尺寸、入场动画、减弱动效和低性能档位行为。
- 提供 Windows x64、Windows ARM64、macOS Apple Silicon 和 Linux x64 四类桌面安装包。
- Release 工作流新增只构建并上传候选工件、不发布 Release 的手动模式。

完整变更见 [CHANGELOG](https://github.com/177911-juling/Juling-Harness/blob/v1.0.1/CHANGELOG.md)。

## 安装与更新

- 从 v1.0.0 本机开发签名包升级时，请下载本页完整安装包；该版本未附带正式 CI 更新目录。
- Windows Setup 尚无 Authenticode 签名，SmartScreen 可能提示「未知发布者」。
- macOS 采用 ad hoc 签名，尚未经过 Apple 公证；首次打开被拦截时，可在「系统设置 → 隐私与安全性」选择「仍要打开」。
- Linux x64 以 Ubuntu 24.04、glibc 2.39 和 AVX2 处理器为基线；AppImage 需要 FUSE 2。详见 [Linux 客户端](https://github.com/177911-juling/Juling-Harness/blob/v1.0.1/docs/linux.md)。
- Runtime 与更新清单使用 Ed25519 发布密钥验证；操作系统安装包签名是独立的信任层。
