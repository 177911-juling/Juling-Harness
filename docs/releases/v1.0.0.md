# Juling Harness 1.0.0

Juling Harness 1.0.0 是面向 AI 编码代理的桌面工作台：多会话工作区、Agent Hub、模型与供应商管理、SSH、内置浏览器、文件查看、Diff 与 Time Travel。内置 Runtime 为 **OMP 18.20.2 / `18.20.2-harness.18`**。

## 本版内容

- **Agent Hub 指挥台**：按编队、时间线、星图和通讯查看子代理；Agent 详情重做，统一像素头像，BTW 铺满面板，列表滚动时详情固定在视口内。
- **Agent 间真实消息**：消息标签、指挥台通讯与星图连线读取同一份真实投递记录，一次广播合并为一条，停驻、结束和重启后的历史都可查看。
- **模型与供应商**：从接口拉取模型后支持搜索、状态筛选和批量勾选；新建供应商默认展开模板，Gateway / 聚合分组置顶。
- **六语界面**：简体中文、English、Русский、日本語、한국어、हिन्दी；左侧 rail 统一导航，统计面板完成中文化。
- **会话与性能**：切换会话保留草稿、滚动位置和展开内容；近期会话复用首屏；流式输出减少重复渲染、重排和高亮计算。
- **Linux 应用内更新**：AppImage 与 deb 支持检查、验签、后台差分下载和重启更新；启动失败时自动回滚上一版本。
- **文件与工作区**：文件树、文件查看器、工作区失效恢复、Git Diff 与 Time Travel。

完整变更见 [CHANGELOG](https://github.com/177911-juling/Juling-Harness/blob/v1.0.0/CHANGELOG.md)。

## 安装说明

1. 下载并运行 Windows x64 安装程序，按向导完成安装。
2. 首次启动需要本机可用的 Runtime 与模型凭据；应用内「设置 → 模型与供应商」可配置 OpenAI、Anthropic、Ollama 或自定义网关。
3. 桌面端与内置 Runtime 随安装包一起交付，无需单独安装 CLI。
4. 本安装包由本机构建，未使用 CI 发布签名密钥；正式自动更新请使用后续由 Release 工作流生成的安装包。

## 系统要求

- Windows 10 1809 或更高版本，x64
- 建议 8 GB 以上内存；运行本地模型或大量子代理时更高
- 需要网络访问所配置的模型供应商；SSH 与内置浏览器功能按需使用
