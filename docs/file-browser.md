# 文件浏览器

文件浏览器用于浏览当前对话执行位置上的文件。本机对话显示本机磁盘与主目录，SSH 对话显示远端机器；它覆盖整台机器，而不只是当前项目。Explorer 继续负责项目内文件，两者可以互相定位。

当任务需要读取项目外的配置、查看日志、临时编辑单个文件，或在远端机器上处理多个目录时，用文件浏览器比反复切换项目更直接。它默认以 960 × 600 的浮窗打开，也可以停靠、移动或添加多个实例。

## 打开方式

从工作台的“添加工具”打开文件浏览器，或在命令面板搜索“打开文件浏览器”。

- 每个实例分别记住路径、视图、排序、隐藏文件开关和位置栏宽度。
- 固定文件夹按连接目标共享，不随实例变化。
- 真实数据和演示数据的记忆相互隔离。

## 浏览与导航

窗口宽度决定默认布局，手动选择会被记住：

| 窗口宽度 | 默认布局 |
|---|---|
| 小于 480px | 单树，位置入口收进工具栏 |
| 480–900px | 位置栏与详细列表，可切换到树 |
| 900px 及以上 | 分栏，可切换到树或列表 |

窗口变窄时临时降级，恢复宽度后回到原选择。列表可按名称、修改时间、类型和大小排序，目录始终排在文件之前。分栏选中文件后显示信息与文本开头或图片预览。

位置栏提供主目录、桌面、下载、文档、图片、已注册项目、固定文件夹以及磁盘／卷。Windows 本机的常用目录来自系统已知文件夹，因此支持 OneDrive 重定向。点面包屑空白处或按 Ctrl+L（macOS 为 Command+L）输入路径，支持 `~`、带空格或带引号的路径。

筛选只作用于当前文件夹中已加载的条目，不会跨目录搜索。

常用快捷键：

| 动作 | 快捷键 |
|---|---|
| 在列表中移动 | 方向键、Home／End、Page Up／Down |
| 打开 | Enter |
| 返回上一级 | Backspace 或 Alt+↑ |
| 后退／前进 | Alt+←／→ |
| 刷新 | F5 |
| 筛选 | Ctrl／Command+F |
| 切换隐藏文件 | Ctrl／Command+Shift+. |

分栏内可以用左右方向键沿目录层级移动。

## 固定与筛选

- 固定文件夹用于把常用目录留在位置栏；固定关系按连接目标共享。
- 隐藏文件开关按实例记住；Windows 与 Unix 的判定规则不同，见[范围与限制](#范围与限制)。
- 筛选在当前文件夹内即时生效，只匹配已经加载的条目。
- 排序方式按实例记住，窗口变窄时视图降级但排序不变。

## 打开与编辑

双击文件会打开内置文件窗口。项目内文件使用其工作区身份，与 Explorer 共用缓冲区并显示 Git 标记；其他文件显示“项目外”。文本沿用 UTF-8、带 BOM 的 UTF-16、换行格式保留、版本冲突处理和未保存关闭确认，编辑上限为 8 MiB。PDF、图片、媒体、表格和 Office 预览沿用现有[文件查看器](file-viewer.md)及可选组件。

右键菜单提供系统程序打开、打开方式、在系统文件管理器中定位、复制路径、添加到对话、固定文件夹，以及设为项目并新建对话。

- 加入当前项目文件时使用相对路径；项目外文件或其他项目的文件使用绝对路径，使引用仍指向原文件。
- 复制远端路径得到的是远端机器的路径。

文件管理：

| 操作 | 方式 | 说明 |
|---|---|---|
| 新建文件夹 | Ctrl／Command+Shift+N | 名称冲突会显示错误 |
| 重命名 | F2 行内编辑 | 不会覆盖已有文件 |
| 移到回收站 | Delete（macOS 也可用 Command+Backspace） | 先弹出确认，没有永久删除 |
| 在 Explorer 中定位 | 项目目录或文件的右键菜单 | 回到项目树 |

已注册项目根目录回收时会有额外提示。确认后只移到系统回收站／废纸篓，不提供永久删除。磁盘和卷根目录不能重命名或回收。符号链接可以浏览，内置编辑器不会通过文件末端的符号链接写入目标。

Explorer 的目录右键菜单同样提供“在文件浏览器中显示”，两个入口互相定位。

## 本机与 SSH 差异

SSH 文件的列表、文本读写和资源预览通过所属目标的 Host 传输。新建文件夹、重命名和设为项目同样在远端执行。

| 能力 | 本机 | SSH |
|---|---|---|
| 列表、读写、预览 | 本机文件系统 | 通过 Host 传输，在远端执行 |
| 新建、重命名、设为项目 | 本机 | 在远端执行 |
| 系统程序打开、打开方式、定位 | 可用 | 禁用，并说明远端文件不在本机 |
| 回收站 | 系统回收站／废纸篓 | 禁用 |

旧 Host 会提示更新；断开时保留路径和界面状态，可在连接恢复后刷新。

## 预览与真实数据边界

预览开关打开时只显示演示文件系统，新建、重命名和回收只修改内存中的 fixture，不执行真实文件操作。关闭预览后只读取 Host 数据。

`?preview=1&marks=off` 隐藏演示标记和演示专用提示。

## 范围与限制

- 目录最多返回 5000 项，并显示截断提示；没有递归搜索。大列表和分栏按可见区域渲染。
- Windows 隐藏属性暂用名称近似：点开头文件和常见系统文件名视为隐藏；Unix 使用点开头规则。
- Windows 盘符并行探测，约 400ms 内没有返回容量的驱动器显示未就绪。UNC 路径可以直接输入。
- 当前没有后台文件监听。F5、刷新按钮、重新显示窗口以及文件操作完成后会重读；文件编辑器继续使用自己的版本检测。
- 常用目录仅列出实际存在的位置。没有权限、路径不存在和驱动器未就绪会显示具体错误。
- macOS／Linux 的无覆盖重命名通过系统 Perl 调用内核的独占重命名操作，需要 `/usr/bin/perl`。macOS 自带；精简 Linux 主机若未安装会提示安装。文件系统不支持独占重命名时返回错误，不降级为可能覆盖文件的操作。
